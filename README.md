# Ovale Spell Priority (3.3.5a Modernized)

Модернизированная версия аддона **Ovale** (v3.3.35) для World of Warcraft: Wrath of the Lich King (3.3.5a).

## Основные изменения и оптимизации
- **Оптимизация OnUpdate:** тяжелый расчет дерева действий переведен на интервальный таймер (троттлинг 0.05с) с мгновенным пересчетом по боевым событиям (касты, кулдауны).
- **Поддержка Masque / LibButtonFacade:** корректное применение скинов кнопок, обрезка мусорных полей текстур (Zoom) и аккуратный 1px контур без скинеров.
- **Интеграция LibDualSpec-1.0:** автоматическое бесшовное переключение профилей ротации при смене специализации талантов.
- **Исправление локализации:** восстановлен и дополнен полный русский перевод (`ruRU`), исправлены поврежденные символы кодировок.
- **OmniCC-совместимость:** отключено наложение встроенного цифрового таймера при активных сторонних аддонах кулдауна.

## Установка
1. Скачайте архив (`Code` -> `Download ZIP`).
2. Распакуйте папку в `World of Warcraft/Interface/AddOns/`.
3. Убедитесь, что папка называется именно `Ovale` (без суффиксов `-main` или `-master`).
